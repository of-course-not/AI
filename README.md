## 目录结构

```
实验1/  路由器基本配置、静态路由、RIP、OSPF（四部分，共 8 学时）
```

## 两处与原题图不一致的地方（已在报告中说明）

1. **实验三的 Cisco 2501 用 2621XM 替代**。Packet Tracer 8.2.2 已不再提供 2501 型号。
   接口对应关系：`Ethernet0` → `FastEthernet0/0`，`Serial0` → `Serial0/0`，`Serial1` → `Serial0/1`。
   设备名仍沿用原图的 2501A / 2501B / 2501C。
2. **实验四的 OSPF 原图未画 PC**，但任务要求"完成 PC 配置"，故补接 PC0 / PC1 / PC2。

另外，实验二报告里说明了两点：

- Packet Tracer 的 Server-PT **没有 Telnet 服务端**，所以"只有 teacher1 能 Telnet 服务器"
  是靠 `Connection refused`（ACL 放行）与 `Connection timed out`（ACL 拒绝）的差异验证的。
- "学生只能访问 server0 的 web" 按**严格理解**实现，因此学生 ping 不通 Server0
  （与"所有服务器都不允许被 ping"这条需求一致）。

## 工程文件怎么用

直接双击用 Packet Tracer 8.2.2 打开即可，拓扑、连线、接口编号、IP、全部配置都已就位。

想自己练手的话，推荐做法是：打开工程 → 抄下配置 → `write erase` 清空 →
自己重新配一遍 → 和原工程对比。**照抄命令交上去最没意义，一问就露馅。**
